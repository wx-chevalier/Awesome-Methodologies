# STP 理论

# 以拓竹Bambu Lab产品线为例讲解 STP 理论
STP = **市场细分Segmentation(S) → 目标市场选择Targeting(T) → 市场定位Positioning(P)**
底层逻辑：先把庞大市场切分，挑选适合自己的人群，最后在用户心中建立独一无二认知；
拓竹完整产品线（A1系列 / P1系列 / X1系列 / H2D工业机型）就是一套教科书级STP落地案例。

## 一、S - Segmentation 市场细分：切分3D打印市场
按照**用户身份、预算、使用场景、需求痛点**，把FDM消费级/商用3D打印大盘拆成多个细分人群：
1. **入门新手细分市场**
预算有限；刚入坑、手办/模型爱好者；怕调试、追求开箱即用；不想折腾复杂参数；对打印稳定性要求一般。
2. **进阶发烧友细分市场**
有打印经验；追求高速、高精度；愿意为更好硬件付费；使用PLA/少量PETG；重视自动化（自动调平、多色）。
3. **专业创作者/小型工作室细分市场**
承接订单、商用接单；长时间连续打印；经常使用工程耗材（ABS/ASA/TPU）；需要腔体恒温、大成型尺寸、高稳定性。
4. **工业B端生产力细分市场**
企业打样、小批量生产；7×24小时持续运转；看重一致性、耗材兼容性、设备运维、产能。

> 重点：细分不是划分产品，是**划分人、划分需求**。

## 二、T - Targeting 目标市场选择：拓竹选择主攻哪些人群
拓竹根据自身技术（高速CoreXY、AMS多色自动供料）、成本、品牌定位，挑选目标客群，并用不同产品线承接不同目标群体：

| 产品线 | 选定目标人群(Target) |
|--------|----------------------|
| A1 / A1 mini | 入门新手玩家；学生、轻度爱好者；首次购买3D打印机 |
| P1S / P1P | 进阶爱好者；手工创作者；预算中等，想要高速+可选多色 |
| X1C / X1E | 专业发烧友、小型接单工作室；追求顶配、腔体恒温、工程耗材能力 |
| H2D | 企业B端、设计工作室、小批量生产商用客户 |

战略选择解读：
拓竹没有只做单一人群，而是**梯度覆盖**，从入门到商用形成产品梯队；同时主动放弃极低价位“玩具级3D打印机”红海市场，不和百元DIY套件内卷。

## 三、P - Positioning 市场定位：占领用户心智（最核心）
**定位 = 在目标客户脑海中，给自己的产品找到一个独特位置，一句话讲清凭什么选你，而不是竞品。**
每条产品线独立定位，互不内耗：
1. **A1系列定位（面向新手）**
> 普通人零门槛的全自动入门高速3D打印机，开箱就能稳定打印。
区别于传统入门机需要手动调平、反复调试；对标市面上各种DIY整机。

2. **P1系列定位（面向进阶玩家）**
> 性价比高速全自动主力机型，兼顾性能与价格，发烧友的实用选择。
介于入门与旗舰之间；拥有X1大部分高速核心能力，精简部分高端配置，控制售价。

3. **X1系列定位（面向专业创作者）**
> 消费级顶配全能旗舰，腔体恒温、原生支持工程耗材，发烧友天花板。
建立“家用/小型工作室性能标杆”心智，和中端机型拉开专业差距。

4. **H2D定位（面向B端）**
> 面向商业生产场景的专业生产力设备，稳定、可持续批量制造。
脱离消费玩家赛道，和工业级打印机竞争，强调商用ROI。

## 四、完整串联：STP落地链路（拓竹案例演示）
以 **P1S** 为例完整跑通STP：
1. **S细分**：市场里存在一批有基础、想要高速打印，但买不起X1旗舰的进阶爱好者
2. **T选择**：选定这群「追求高性能、预算适中的进阶玩家」作为目标客户
3. **P定位**：拥有旗舰级高速打印能力的高性价比全自动机型
👉 后续所有4P（产品配置、定价、宣传、渠道）全部围绕这个定位展开：
- Product：保留高速CoreXY、自动调平、支持AMS，砍掉X1部分高端传感与全封闭恒温腔体
- Price：售价显著低于X1C，拉开价格梯度
- Promotion：测评重点对比“和旗舰接近的打印速度，更低价格”
